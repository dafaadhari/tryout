# 🎓 Sistem Try Out CAT CPNS (Premium SaaS)

Sebuah *platform* simulasi *Computer Assisted Test* (CAT) berstandar BKN yang dirancang khusus untuk persiapan Seleksi Kompetensi Dasar (SKD) Calon Pegawai Negeri Sipil (CPNS). Sistem ini dibangun dengan arsitektur modern untuk memberikan pengalaman ujian yang stabil, realistis, dan berpotensi untuk dikomersialisasikan sebagai layanan SaaS (*Software as a Service*).

## ✨ Fitur Unggulan

- **🖥️ Antarmuka Standar BKN:** Desain UI/UX simulasi ujian *full-width* yang responsif, bersih, dan bebas distraksi, meniru lingkungan ujian aslinya.

- **💾 Real-time Autosave:** Jawaban peserta secara otomatis tersimpan ke *database* di latar belakang (*no-reload*). Tidak perlu khawatir kehilangan data akibat *refresh* halaman atau koneksi terputus.

- **⏱️ Live Countdown Timer:** Waktu ujian berjalan mundur secara presisi dan ujian akan otomatis disubmit ketika waktu habis.

- **📊 Auto-Scoring & Passing Grade:** Penilaian otomatis yang dipisahkan berdasarkan kategori soal (TWK, TIU, TKP) dengan ambang batas kelulusan (*passing grade*) yang dinamis.

- **📈 Dashboard Analitik Peserta:** Menampilkan rekapitulasi komprehensif dari total ujian yang diselesaikan, rata-rata skor, dan status kelulusan.

## 🛠️ Tech Stack

Sistem ini dikembangkan menggunakan teknologi *full-stack* untuk memastikan performa yang cepat dan aman:

- **Backend:** [Laravel](https://laravel.com/) (PHP)
  
- **Frontend:** [React.js](https://reactjs.org/) + [Inertia.js](https://inertiajs.com/)
  
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Database:** MySQL
- **HTTP Client:** Axios
